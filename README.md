## 🚀 How to Run a Project Yourself

1. Open the `.ino` file inside the project folder using the Arduino IDE.
2. Connect your Arduino to your computer via USB.
3. Go to **Tools > Board** and select **Arduino Uno**.
4. Go to **Tools > Port** and select the correct port.
5. Click the **Upload** button (➡️ arrow icon).
6. Watch it come to life!
